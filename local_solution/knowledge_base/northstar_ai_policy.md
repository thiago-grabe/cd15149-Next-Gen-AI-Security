# Northstar AI Usage Policy v2.3

## Purpose

This policy governs the acceptable use of AI-powered tools at Northstar Technologies,
including the Northstar Research Agent.

## Approved Uses

- Research and summarization of internal documentation
- Drafting support tickets and internal notes
- Querying approved knowledge base sources
- Fetching content from approved internal URLs and public reference sites

## Prohibited Uses

- Using the agent to access data outside your authorization level
- Submitting confidential or restricted information to external AI services
- Automating actions that require human approval (e.g., financial transactions,
  personnel decisions, security configuration changes)
- Using the agent to scrape, aggregate, or redistribute employee personal data

## Data Handling

All queries and agent responses are logged for security review.
Employees must not use the agent to process data classified above their own clearance level.
The agent should not be used to store confidential data in its note-saving feature unless
the note is access-controlled appropriately.

## Compliance

Violations of this policy are subject to disciplinary action under Northstar's Code of Conduct.
Repeated or deliberate misuse may result in termination of AI tool access.

## Questions and Reporting

Contact the AI Enablement team: ai-team@northstar-tech.com
Report suspected misuse to: security@northstar-tech.com
