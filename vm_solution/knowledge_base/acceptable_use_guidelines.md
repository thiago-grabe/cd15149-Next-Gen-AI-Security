# Research Agent Acceptable Use Guidelines

**Audience:** All Northstar Technologies employees
**Owner:** AI Enablement Team
**Last updated:** 2025-11

---

## Overview

The Northstar Research Agent is an internal productivity tool that helps employees
research topics, summarize documents, create tickets, and save notes. It is not a
general-purpose AI assistant. These guidelines define what it can and cannot do.

---

## What the Agent Can Do

| Capability           | Description                                           |
|----------------------|-------------------------------------------------------|
| Knowledge base search | Retrieve and summarize documents from Northstar's internal knowledge base |
| URL fetch            | Fetch content from approved internal URLs and public reference sites |
| Create tickets       | Open support tickets in the internal ticketing system |
| Save notes           | Write research summaries to your workspace            |

---

## What the Agent Cannot and Should Not Do

- **Access employee HR records** — use the HR portal directly for personnel data
- **Send emails** on your behalf
- **Make changes to production systems** or infrastructure
- **Access documents above your clearance level**
- **Store notes containing classified or restricted data** without appropriate access controls
- **Execute commands it was not explicitly asked to execute**

---

## Expected Behavior

If the agent produces output that:
- References commands you did not request
- Claims to have access to tools or data not listed above
- Includes employee PII you did not ask for

...this is **unexpected behavior**. Stop the session and report it to the SOC.

---

## Accuracy

Agent outputs are AI-generated and may contain errors or hallucinations.
Always verify critical information with primary sources before acting on it.
